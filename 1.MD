## 1. Needs a decision from you before anyone writes code

### 1.1 Mirroring the images off Wikimedia (the rest of I1)

Attribution shipped. **Mirroring did not**, because it needs two things I was
told not to decide alone.

What was asked: a build-time script that copies the images into our own
storage (Vercel Blob or similar), so a Commons rename or deletion cannot blank
a page.

Why it stopped:

- **It needs a new dependency and a paid product.** `@vercel/blob` plus Blob
  storage for ~2,978 files. Hard rule 6 says no new heavy dependencies without
  your approval, and this one also has a monthly bill.
- **It changes the catalog data files.** Storing a mirrored URL per place means
  editing `src/data/destinations.ts`, which I was told to stop and ask about.

The plan, if you want it:

1. `scripts/mirror-photos.mjs` reads `scripts/photo-credits.json` (already
   committed, already has every filename and the original width), downloads the
   960px thumb for each, uploads to Blob under a content-hashed path.
2. Write the mirrored URL into a **second manifest**, not into the catalog -
   `scripts/photo-mirror.json`, same pattern as `photo-verified.json`. That
   avoids touching the data files at all, and a missing entry falls back to the
   Commons URL.
3. `CardPhoto` / `PlaceThumb` prefer the mirror when present.
4. A fallback image for a file that 404s at both.

Rough cost: ~2,978 files at ~150KB = **~450MB**, well inside Blob's free tier
today but not free at scale. Say the word and it is perhaps half a day.

**Worth knowing:** the legal exposure is already closed. Mirroring is about
reliability and speed, not licensing.

## 6. Traps worth remembering

- **Backticks in a bash heredoc are command substitution.** It silently ate two
  words out of a commit message here. Use the Write tool for anything with
  backticks or regex.
- **Animations do not advance in this headless browser.** Every animation
  reports `playState: running` with `currentTime: 0`, so `fill: both` pins
  elements at their *from* state forever. It made a quiz step measure as
  `opacity: 0, translateX(-28px)` and looked exactly like a layout bug.
  `prefers-reduced-motion` is `false` - it is the compositor clock. **Any
  measurement of an animated element here is unreliable.**
- **Kill a dev server by port, not by name.** `pkill -f "next start"` matches
  nothing on Windows; `netstat -ano | grep :3000` then stop the pid.
- **A stale `.next/types/validator.ts` fails `tsc` after a branch switch** with
  "cannot find module ../../src/app/…". Delete `.next/types` and re-run; it is
  not a source error.
- **`grep -c` returning 0 exits non-zero** and will break an `&&` chain - which
  looks like the command failed when the answer was "zero matches", the result
  you wanted.
